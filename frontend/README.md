# Frontend

This directory contains all frontend-related code for the HANACV2SQL application.

## Structure

- `app`: Next.js app directory
- `components`: React components
- `contexts`: React contexts
- `hooks`: React hooks
- `lib`: Frontend utilities
- `public`: Static assets
- `styles`: CSS and styling
- `types`: TypeScript types
- `utils`: Frontend utility functions

## Development

\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

## Building

\`\`\`bash
npm run build
\`\`\`

## Testing

\`\`\`bash
npm test
